用戶隱私保護與數據安全政策

最後修訂生效日期：2026年10月11日（針對資安透明度與數據防護架構全面修訂）

歡迎使用 Daily Diet 飲食控制助手（包含 Web App 與 LINE 官方帳號機器人）。我們深知飲食紀錄、體態數據與生活作息屬於高度私密的個人健康資訊。本應用程式堅持以「資料自主（Data Ownership）」、「最小化收集」與「透明公開」為最高原則，本政策向您詳盡說明數據的儲存位置、傳輸機制、外部 AI 處理邊界與您的自主控制權。

🩺 重要健康與非醫療用途免責聲明

Daily Diet 與「熊貓教練」所提供之所有熱量（kcal）、蛋白質（g）、水分（ml）、BMR/TDEE 建議、飲食估算及間歇性斷食窗口提醒，均僅供個人日常自我健康管理與體重控制參考，非屬任何形式之醫療診斷、疾病治療或專業臨床處方。
若您患有慢性疾病（如糖尿病、低血糖、腎臟病、心血管疾病）、有進食障礙病史、處於孕期或哺乳期，在進行任何飲食調整或斷食前，請務必諮詢合格執業醫師或註冊營養師。

1. 本地優先架構與資料收集極小化

本服務致力於將伺服器端資料收集降至最低，採用無需註冊帳號密碼的設計：

  • 本地優先儲存（IndexedDB）： 您的餐點日誌、自訂目標、歷史體重與常用餐點皆優先且完整儲存於您本地裝置之瀏覽器資料庫中。在未開啟雲端同步時，應用程式具備 100% 離線運作能力，資料完全不離開您的手機或電腦。
  • LINE 平台連動（LIFF / Bot）： 當您透過 LINE 發送飲食訊息或照片時，系統僅接收 LINE 平台分配之用戶虛擬識別碼（LINE User ID），以利為您綁定個人專屬雲端空間。我們絕不主動收集您的真實姓名、電話號碼、通訊錄、定位軌跡或信用卡號碼。

2. 雲端同步架構（GitHub Secret Gist 儲存邊界與安全告知）

為達成跨裝置（電腦、手機瀏覽器與 LINE 機器人）即時雙向同步，系統採用 GitHub Gist 作為雲端中繼存儲：

  • 儲存機制（Secret Gist / 未公開網址）： 每位啟用雲端同步的用戶，其飲食與體態資料均被寫入至專屬的 Secret GitHub Gist 空間中。
  • 【明確資安告知與邊界】 依據 GitHub 官方架構說明，Secret Gist 屬於「未被搜尋引擎或 Explore 頁面公開索引的 Unlisted 網址」，其並非由帳號密碼鎖定之完全封閉私有庫，任何取得該隨機 Gist ID 網址者均可能直接檢視內容。
  • 後端存取控制與防護： 系統伺服器（Google Apps Script）部署了用戶 ID 與 Gist 擁有權嚴格比對機制（防範越權存取 IDOR），絕不對外公開用戶之 Gist ID。
  • 用戶隱私建議： 鑑於上述特性，我們強烈建議使用者勿在紀錄或備註中填寫身分證字號、姓名全名、病歷密碼或機密資訊。若您對雲端儲存有更高隱私要求，可選擇：
    ① 於 Web App 設定中「解除雲端綁定」，採用純本機離線模式；
    ② 在進階設定中填入個人專屬 GitHub PAT（Personal Access Token），將備份權限直接歸屬於您個人名下的 GitHub 帳號。

3. AI 影像與語意辨識服務條款（Google Gemini 雲端推論透明度告知）

【法定告知義務】 當您使用拍照辨識或 AI 飲食拆解功能時，您傳送的照片與菜名將傳輸至第三方 AI 雲端模型（Google Gemini）進行多模態影像推論與語意分析，以提取食物營養特徵並估算熱量、蛋白質與水分。

  • 傳輸層加密（In-Transit Encryption）： 系統全程採用 HTTPS / TLS 1.3 企業級傳輸層加密安全通道 傳輸圖片與文字，防範傳輸過程中的中途竊聽與攔截。
  • 非端到端加密（Non-E2EE）揭露： 由於第三方 AI 模型必須於雲端運算節點將數據解碼為張量矩陣以執行即時推論，此過程屬於雲端推論處理，並非端到端加密（End-to-End Encryption）。Daily Diet 絕不對外公開發布您的相片，但建議使用者避免上傳拍攝到清晰個人面孔、身分證件或私密居家背景之照片。
  • 推論性質提示： AI 模型之辨識數據為演算法統計估算，非屬精密儀器量測，建議您依實際攝取情況手動微調。

4. 使用者體驗遙測與分析（Microsoft Clarity 嚴格全域遮蔽）

為監控頁面崩潰並持續優化介面流暢度，本 Web 應用程式導入了微軟 Microsoft Clarity 體驗分析工具：

  • 嚴格全域客戶端遮蔽（Strict Client-side Text Masking）： 前端網頁已在 HTML 根節點配置 data-clarity-mask="true" 嚴格脫敏指令。所有文字內容（包含您的餐點品名、熱量數字、體重紀錄、自訂目標及所有輸入框文字）均在瀏覽器端即時轉化為星號（*）遮蔽，微軟伺服器與開發人員均無法窺探您的具體日記文字。
  • 僅收集操作動線： 遙測資料僅限於無關個人隱私之滑鼠點擊座標、滾動比例、螢幕解析度與系統崩潰日誌。

5. 伺服器運作日誌脫敏與自動銷毀機制

  • 去識別化遮蔽： 為保障用戶隱私，系統伺服器（GAS）運作日誌中一律將用戶 ID 進行脫敏遮蔽（僅顯示末尾 6 碼，如 ...497c66）。
  • 先進先出動態覆蓋： 伺服器僅採先進先出（FIFO）暫存最近 60 筆執行事件用於連線除錯，超出即自動永久覆蓋銷毀，絕不留存歷史對話快取。

6. 資料自主權、匯出與被遺忘權（刪除資料）

依據個人資料保護法與現代數據自主精神，您隨時享有完整的資料控制權：

  • 隨時一鍵匯出（資料可攜性）： 您可在 Web App「設定 ➔ 資料與備份」中點擊「📥 匯出完整 JSON 備份」，隨時將本機所有歷史飲食日誌、體重與偏好完整下載備份至您的裝置。
  • 徹底抹除本機（被遺忘權）： 您可在 Web App「設定 ➔ 資料與備份」中點擊「🗑️ 抹除本機所有資料」，系統將經雙重確認後永久清空本機瀏覽器（IndexedDB）所有數據與本機快取。
  • 解除雲端同步： 點擊「解除雲端綁定」可立即切斷本機與雲端 Gist 的同步關聯，停止任何雲端資料傳輸。
  • 雲端 Gist 備份之特性： 由於 GitHub Gist 具備 Git 版本歷史紀錄特性，若您欲覆蓋雲端紀錄，可清空本機後點擊「手動同步」將空白備份推送覆蓋最新版；若使用個人 GitHub PAT，亦可隨時登入 GitHub 直接徹底刪除該 Gist 及其所有版本紀錄。
