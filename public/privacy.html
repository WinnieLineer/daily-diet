用戶隱私保護與數據安全政策

最後修訂日期：2026年8月30日

歡迎使用 Daily Diet 飲食控制助手（包含 Web App 與 LINE 官方帳號機器人）。我們深知飲食紀錄與體態數據屬於高度私密的個人健康資訊，因此本應用程式全面貫徹「隱私設計（Privacy by Design）」與「去中心化儲存」架構，讓您擁有 100% 的個人數據掌控權。

🩺 重要健康與非醫療用途免責聲明

Daily Diet 與「熊貓教練」所提供之所有熱量（kcal）、蛋白質（g）、水分（ml）、BMR/TDEE 建議及飲食估算，均僅供個人日常自我健康管理與體重控制參考，非屬任何形式之醫療診斷、疾病治療或專業臨床處方。
若您患有慢性疾病（如糖尿病、腎臟病、心血管疾病）、處於孕期或哺乳期，在進行任何激進的飲食或熱量限制前，請務必諮詢合格執業醫師或註冊營養師。

1. 資料收集與極小化原則

本服務致力於將資料收集降至最低，採用無需註冊密碼的無感連動設計：

  • 本地瀏覽器儲存（IndexedDB）： 您的餐點日誌、自訂目標、歷史體重皆優先儲存於您本地裝置之瀏覽器中，離線亦可正常運作。
  • LINE 平台連動（LIFF / Bot）： 當您透過 LINE 發送飲食訊息或照片時，系統僅接收 LINE 平台分配之用戶虛擬識別碼（LINE User ID），以利為您綁定個人專屬雲端空間。我們絕不主動收集您的真實姓名、電話號碼、通訊錄或信用卡號碼。

2. 雲端隔離儲存（GitHub Gist 私有空間）

為達成跨裝置（電腦、手機、LINE）即時同步，系統採用專屬的私有雲端儲存：

  • 每位用戶的飲食與體態資料均被獨立寫入至 私有（Secret）GitHub Gist 空間。
  • 私有 Gist 具備存取權限隔離機制，不會被公開搜尋引擎索引，亦不會與其他用戶資料混合儲存。
  • 我們絕不將您的個人飲食資料用於廣告行銷推播或出售給第三方資料庫。

3. AI 影像與語意辨識服務（Google Gemini）

當您在 LINE 或 Web 介面上傳餐點照片或輸入食物文字時：

  • 系統透過安全加密連線將圖片與文字傳送至 Google Gemini AI 模型 API 進行影像特徵提取與營養素預估。
  • AI 僅於請求期間進行即時推論，分析完成後即完成交付，Google 不會將您的照片用於公開發佈。

4. 實時日誌脫敏與自動銷毀機制

  • 去識別化遮蔽： 為保障用戶隱私，系統運作診斷日誌中一律將用戶 ID 進行脫敏遮蔽（僅顯示末尾 6 碼，如 ...497c66）。
  • 動態輪替銷毀： 運作伺服器（Google Apps Script）僅採先進先出（FIFO）暫存最近 60 筆執行事件用於連線調試，超出即自動永久覆蓋銷毀，不建立永久對話快取。

5. 資料自主權與被遺忘權（刪除資料）

依據個人資料保護規範，您隨時享有完整的資料控制權：

  • 單筆與今日刪除： 您可隨時在 LINE 輸入「刪除最後一筆」或在管理清單點擊「🗑️ 清空今日所有紀錄」。
  • 完全銷毀權（被遺忘權）： 您可在 Web App「設定 ➔ 資料與備份」中一鍵「清除本機資料」或重置 Gist ID，徹底抹除所有儲存數據。
  • 資料匯出： 您可在 Web 端隨時一鍵匯出完整 JSON 備份檔，實現資料無障礙遷移。

6. 條款變更與聯繫管道

若本隱私政策有任何重大修訂，我們將於應用程式內公告。若您對個人隱私保護有任何疑慮，歡迎透過 Web App「設定 ➔ 意見回饋」與開發團隊聯繫。
